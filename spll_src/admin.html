申込時に選ばれた利用目的から、契約書の別紙2（利用条件・利用料条件）を自動計算して反映します。計算方式は RATE（売上連動＝率）／FLAT（定額・契約単位）／PER_WORK（原作数比例＝単価×原作数）。金額・率・文言は事務局が編集してください。

CloudSign API 設定

ScriptProperties（secretはマスク）

締結Webhookの受信（書類タイトルの取得API・突合フォールバック）と、清算計算書のCloudSign送信に使用します。申込契約の作成・送信はクラウドサインフォーム側が行うため、GASからは送信しません。Client Secret は保存時のみ入力してください（空欄なら現在値を据え置き）。

締結Webhookのペイロードは documentID / status(2=締結完了) / userID / email / text のみで、フォーム入力値は含まれません。application_ref は契約書タイトルに含めることで突合します（取れない場合は書類取得APIでタイトルを引くフォールバックあり）。秘密情報は ScriptProperties に保存され画面には再表示されません。試験運用のためサンドボックスを既定で使用します。

クラウドサインフォーム（powered by formrun）連携

ScriptProperties（secretはマスク）

公開ポータルで発行した application_ref を、クラウドサインフォームのhidden項目に引き継ぎ、申込→締結を突合します。Webhook Secret は保存時のみ入力してください。

application_ref＋原作×N＋別紙2 の全キーを生成。各値に formrun の _field_xxxx を入力してください。
連携の要点（クラウドサインフォームの仕様に基づく）：
  1. フォームにhidden項目を作成し、契約書テンプレートの差込フィールドに対応させます：application_ref と、対象原作分の work_id_1..N / work_title_1..N（Nは上の「最大数」）。各hidden項目のキー（_field_xxxx）を「hidden項目マッピング」にJSONで登録してください。
  2. 公開ポータルは、選択された原作を フォームURL?_field_aaaa=REF-…&_field_bbbb=WRK-…&_field_cccc=作品名… の形で自動的に引き継ぎます（未選択の枠は空文字）。
  3. 締結の自動突合のため、CloudSignの書類タイトルに application_ref を含める設定にしてください（締結Webhookはフォーム入力値を含まず、タイトルで突合。取れない場合は書類取得APIのフィールド走査→手動紐付けにフォールバック）。
  4. 契約書テンプレートは対象原作を最大 N 件の固定枠で持ちます（別紙1）。ポータルの選択数もこの「最大数」に制限されます。
  5. formrunのWebhook（送信専用・PROFESSIONALプラン）を GAS② の doPost?hook=formrun に向けると、申込を「締結待ち」へ前進できます（任意）。
  6. 利用には、CloudSignのAPI利用可能プラン＋API利用申込＋クラウドサインFORM申込が必要です。

X（Twitter）連携

ScriptProperties（secretはマスク）

作品を「公開(PUBLISHED)」にした時にX（Twitter）へ告知投稿します。API v2 / OAuth1.0a のキーを登録してください。secretは保存時のみ入力。

認証バッジ（クレジット表記）

ScriptProperties

契約締結時（B経路固定）に、認証バッジを PNG 3サイズ（大/中/小）で自動生成し、検証ポータル／提出リンクから利用者が取得できます（当社からのメール送信はしません）。テンプレートSlides ID を指定すると差込（{{work_name}}/{{license_id}}/{{issued_at}}/{{credit}}）で生成、未指定なら暫定デザインを自動組版します。

Xの秘密情報・バッジ設定はGASのScriptPropertiesに保存され、画面には再表示されません（設定済みか否かのみ表示）。

管理者とロール（RBAC）

Admin_Users ／ 全 admin_ 関数はサーバー側で権限を強制

ロール別に管理者を登録します：SYSTEM_ADMIN（全設定）／LEGAL_ADMIN（規約・審査・認証）／OPERATIONS（作品・提出・審査）／ACCOUNTING（報告承認・請求・入金・清算）／AUDITOR（閲覧のみ）。初回登録はGASエディタで setup_setInitialAdmin("メール","SYSTEM_ADMIN") を実行してください（公開URLからの初回登録は廃止）。
