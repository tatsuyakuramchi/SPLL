作品審査管理

Geminiの一次審査結果（PASS/REVIEW/HIGH_RISK）を受けて、人手判断（承認・是正要求・エスカレーション）を行います。A作品は締結前、B作品は締結後の提出。

審査キュー

AI_Review_Jobs / AI_Findings より
提出ID作品経路AI結果主な指摘人手判断
AI結果は一次スクリーニングで、承認・適法性保証ではありません。最終判断は人手で行い、判断はEventsへ記録されます。

契約管理

FormRun申込→CloudSign API送信→締結の状態を一覧。締結有無はCloudSignのWebhookでSheetsへ自動書き戻し。

契約一覧

Applications / Contracts より
契約ID申込ID作品契約者締結状態締結日操作
締結状態の遷移（送信済→締結済／辞退／取消）はCloudSign Webhook（COMPLETED等）またはAPI照合バッチのみが更新します。手動での締結化はできません。

半期清算・計算書

公開申込窓口で表示する同意文・規約、作品マスタ（スプレッドシート）、外部API（CloudSign・FormRun）の接続設定を管理します。保存内容は即時に反映されます。

個人情報の取得同意文

Config: LEGAL_PRIVACY_TEXT

申込ウィザードのステップ1で表示されます。HTML可（<h4> / <ol> / <li> 等）。

利用規約テンプレート

Config: LEGAL_TERMS_TEMPLATE

差込トークン： {{name}} 作品名 ／ {{pub}} 出版社 ／ {{ok}} 許諾要素 ／ {{no}} 禁止要素 ／ {{media}} 媒体 ／ {{fee}} 許諾料 ／ {{credit}} クレジット。作品ごとに自動で差し込まれます。

データソース接続

ScriptProperties

作品マスタ・業務台帳のスプレッドシートIDや保存先を設定します。未入力の項目はコード既定値（プレースホルダ表示）が使われます。

作品一覧（Works_Master）

作品ID作品名出版社審査公開状態操作

作品を追加

Works_Master へ upsert
公開状態を PUBLISHED にした作品のみ、公開申込窓口（api_listWorks）に表示されます。審査タイミング(A/B)は内部属性で、公開UIにはバッジを出しません。

CloudSign API 設定

ScriptProperties（secretはマスク）

電子契約の送信・締結Webhookに使用します。Client Secret は保存時のみ入力してください（空欄なら現在値を据え置き）。

秘密情報はGASの ScriptProperties に保存され、画面には再表示されません（設定済みかどうかのみ表示）。

FormRun 設定

ScriptProperties（secretはマスク）

申込フォーム（FormRun）と createApplication_ の連携設定。Webhook Secret は保存時のみ入力してください。
