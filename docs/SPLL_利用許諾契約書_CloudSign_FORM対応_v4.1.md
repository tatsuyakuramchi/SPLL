## 第1条（契約の構成）

1. 本契約は、前記個別条件、本契約本文及び契約成立時に適用される「SPLL二次創作ガイドライン」（以下「ガイドライン」といいます。）により構成されます。
2. 個別条件と本契約本文が抵触する場合は個別条件を優先し、本契約本文とガイドラインが抵触する場合は本契約本文を優先します。
3. 本契約における「事務局」とは、SPLL制度の契約管理、SPLL番号の管理、利用状況の確認その他SPLL制度の運営事務を行うTRPGライツ事務局をいいます。

---

## 第2条（利用許諾）

1. ライセンサーは、利用者に対し、本契約の条件に従い、個別条件に記載された対象作品を利用して二次創作活動を行うための非独占的かつ譲渡不能な権利を許諾します。
2. 前項の許諾範囲は、個別条件及びガイドラインに定める利用区分、利用地域その他の条件に限られます。
3. 本契約は、対象作品に係る著作権、商標権その他の権利そのものを利用者に移転するものではありません。
4. 利用者は、本契約の範囲を超える利用を希望する場合、あらかじめ事務局へ申し出て、必要な追加契約その他の手続きを行うものとします。

---

## 第3条（利用者資格及び表明保証）

1. 利用者は、本契約の締結時及び契約期間中、次の各号を満たすものとします。
   1. 個人であること。
   2. 成年者であること。ただし、未成年者について事務局が別途定める手続により法定代理人の同意が確認された場合を除きます。
   3. 申込フォームその他事務局へ提供した情報が真実かつ正確であること。
   4. 本契約の締結及び履行に必要な権限を有すること。
   5. 本契約及びガイドラインを遵守すること。
2. 二次創作物の著作者が複数いる場合、利用者は、他の著作者その他必要な権利者から、本契約に基づく利用に必要な権限又は同意を得ていることを表明し保証します。
3. 利用者は、対象作品以外の第三者の著作物、写真、楽曲、素材その他の権利を利用する場合、自らの責任で必要な権利処理を行います。
4. 法人による利用は、事務局が別途法人向け制度を定めた場合を除き、本契約の対象外とします。

## 第4条（利用条件）

1. 契約期間、利用地域、利用区分その他の利用条件は、個別条件に定めるとおりとします。
2. 個別条件に自動更新の定めがある場合、利用者又はライセンサーが個別条件所定の期限までに更新しない旨を通知しない限り、本契約は同一条件で更新されます。
3. 追加製造、利用区分の変更、対象作品の追加その他個別条件の変更を伴う利用について、事務局が追加手続を指定した場合、利用者は当該手続きを行います。

---

## 第5条（利用許諾料及び利用報告）

1. 利用者は、個別条件に定める利用許諾料を、同欄に定める方法及び期限に従い、個別条件に記載の振込先へ支払います。振込先は本契約書にのみ記載し、事務局が電子メール等で口座情報を通知することはありません。
2. 個別条件に利用報告が必要である旨が定められている場合、利用者は、事務局が指定する方法により、指定された期限までに利用実績を報告します。
3. 利用報告に基づき利用許諾料が確定する契約について、利用者は、売上、頒布数その他料金算定に必要な情報を正確に報告するものとします。
4. 支払代行事業者その他事務局が指定する事業者を通じて利用許諾料を支払うことが認められている場合、当該事業者への支払が利用者の本条に基づく支払として取り扱われる範囲は、個別条件又は事務局の案内に従います。

---

## 第6条（クレジット及びSPLL表示）

1. 利用者は、事務局が別途指定する権利表記その他のクレジットを、ガイドラインに従い表示します。指定された権利表記は、SPLL番号に紐づく案内ページ及び認証バッジのQRコードから確認できる検証ページに表示され、締結時点の内容を正本とします。
2. SPLL番号、SPLLロゴ又はSPLLバッジの使用が認められる場合、利用者は、事務局が指定する方法でこれを表示します。
3. SPLL番号、SPLLロゴ又はSPLLバッジは、当該二次創作物が公式作品又は公認作品であることを意味するものではありません。
4. 利用者は、「公式」「公認」その他ライセンサー又は事務局による公式な承認があると誤認させる表示をしてはなりません。

## 第7条（作品提出、確認及び是正）

1. 事務局は、SPLL制度の運営、契約管理及び権利保護のため、利用者に対し、二次創作物、公開URLその他必要な情報の提出を求めることができます。
2. ライセンサー又は事務局は、契約成立後、二次創作物並びにその広告、宣伝、公開及び頒布状況を確認することができます。
3. 前二項の提出、確認、SPLL番号の付与、認証処理又はバッジの発行は、別途明示された場合を除き、当該二次創作物の内容をライセンサーが公式に承認、保証又は推奨することを意味しません。
4. 利用者の行為又は二次創作物が本契約若しくはガイドラインに違反し、又は違反するおそれがあると合理的に判断される場合、ライセンサー又は事務局は、利用者に対し、表示若しくは内容の修正、公開若しくは頒布の停止、削除その他合理的に必要な是正措置を求めることができます。

   2. 第三者の氏名、肖像、容貌、声、芸名、筆名、署名その他個人を識別し得る要素を、本人その他正当な権利者の承諾なく、肖像権、プライバシー権、パブリシティ権その他人格上又は財産上保護される利益を侵害する態様で利用する行為

   9. 現実の暴力、犯罪、テロリズム、暴力的過激主義、人身取引、性的搾取その他重大な違法行為について、これを実行する意思を示し、具体的に扇動、募集、支援、仲介若しくは遂行方法の提供を行う行為

   11. 他人又は他の団体になりすまし、又はAIその他の技術を用いて第三者の声、容貌その他の特徴を本人の承諾なく模倣することにより、当該第三者が二次創作物を制作、承認、推奨又は支持しているとの誤認を生じさせる行為

   15. 法令又は公序良俗に反する行為

   17. その他、SPLL制度の目的、対象作品の権利保護又は第三者の権利利益の保護に照らし、合理的な理由により不適切と認められる行為

## 第9条（二次創作物の権利）

1. 利用者が新たに創作した部分に係る著作権は、利用者又は実際に当該創作を行った者に帰属します。
2. 対象作品及びこれに係る著作権、商標権その他従前から存在する権利は、ライセンサーその他従前の権利者に留保されます。
3. 利用者は、二次創作物の制作又は利用により第三者との間で紛争が生じた場合、自らの責任と費用でこれに対応します。ただし、当該紛争がライセンサーの責めに帰すべき事由によって生じた場合はこの限りではありません。

## 第10条（SPLL番号及び契約上の地位）

1. 利用者は、事務局が付与するSPLL番号を、事務局が指定する方法に従い管理します。
2. 利用者は、ライセンサーの事前の承諾なく、本契約上の地位又は本契約に基づく権利義務の全部若しくは一部を第三者に譲渡、承継、貸与又は担保設定してはなりません。
3. SPLL番号の付与単位その他の管理ルールは、事務局が別途定める運用ルールに従います。

## 第11条（契約の終了及び解除）

1. 本契約は、個別条件に定める期間満了、更新停止、当事者間の合意又は本条に定める解除により終了します。
2. 当事者の一方が本契約に違反した場合、相手方は、相当の期間を定めて是正を求め、当該期間内に是正されないときは、本契約の全部又は一部を解除することができます。
3. 前項にかかわらず、次の各号のいずれかに該当するときは、相手方は催告なく直ちに本契約を解除することができます。
   1. 第3条の表明保証に重大な違反があったとき
   2. 第8条の禁止事項に重大な違反があったとき
   3. 権利侵害その他違反の性質上、是正が困難であるとき
   4. 支払停止、支払不能、破産手続開始その他信用状態に重大な変化が生じたとき
   5. その他本契約を継続し難い重大な事由があるとき
4. ライセンサー又は事務局は、緊急の権利保護が必要な場合、解除に先立ち又は解除と併せて、利用の一時停止その他必要な措置を求めることができます。

## 第12条（終了後の取扱い）

1. 本契約が終了した場合、利用者は、その後新たに本ライセンスを利用した二次創作物を製造、複製、公開、頒布又は配信してはなりません。
2. 終了時点で既に製造済みの在庫、公開済みコンテンツその他の取扱いは、終了原因、違反の有無その他の事情に応じ、事務局又はライセンサーの合理的な指示に従うものとします。
3. 重大な契約違反を理由として解除された場合、ライセンサーは、権利保護のため必要な範囲で、公開停止、削除、在庫頒布停止その他の措置を求めることができます。
4. 既に支払われた利用許諾料は、法令上返還が必要な場合又はライセンサーの責めに帰すべき事由がある場合を除き、契約終了のみを理由として返還されません。

5. 本契約に関する通知その他の連絡は、利用者が登録した電子メールアドレスその他事務局が指定する電子的方法により行うことができます。
6. 利用者は、登録した電子メールアドレスその他の連絡先に変更が生じた場合、事務局が指定する方法により変更を届け出るものとします。

## 第17条（本契約及びガイドラインの変更）

1. 個別条件の変更は、当事者間で別途合意した場合に限り行います。
2. ライセンサー又は事務局は、法令の変更、SPLL制度の運営上の必要その他合理的な理由がある場合、民法その他の法令に従い、本契約の共通条件又はガイドラインを変更することがあります。
3. 前項の場合、変更内容及び効力発生日を、SPLLウェブサイトその他適切な方法により周知します。
4. 対象作品、利用区分、利用許諾料その他個別条件として合意した事項を利用者に不利益に変更する場合は、法令又は本契約に別段の定めがある場合を除き、利用者の同意を得ます。

## 第18条（準拠法及び管轄）

1. 本契約は日本法に準拠します。
2. 本契約に関して紛争が生じた場合、ライセンサー及び利用者は、まず誠実に協議して解決を図るものとします。
3. 協議によって解決しない場合、事務局運営者の本店所在地を管轄する地方裁判所又は簡易裁判所を、第一審の専属的合意管轄裁判所とします。

## 第19条（存続）

第9条、第12条、第14条、第16条、第18条その他その性質上契約終了後も存続すべき条項は、本契約終了後も有効に存続します。
