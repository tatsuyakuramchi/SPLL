## 確認事項

1. 本個別契約は、事務局が本書を利用者の登録メールアドレスへ送付した時点で成立しています（基本契約第3条第3項）。
2. 本書の内容が申込みの内容と異なる場合は、本書の送付から7日以内に事務局へお申し出ください（基本契約第3条第4項）。
3. 利用許諾料は、支払期限までに基本契約第6条に記載の振込先へお支払いください。事務局が本書や電子メールで口座情報をお知らせすることはありません。支払期限までにお支払いがない場合、認証が一時停止されることがあります（基本契約第6条第4項）。
4. 本個別契約の成立後、事務局の案内に従い二次創作物を提出し、審査を受けてください（基本契約第8条）。
5. 基本契約が終了した場合、本個別契約も同時に終了します（基本契約第12条第3項）。
