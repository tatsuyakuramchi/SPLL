## 確認事項

1. 本個別契約は、利用者が電子契約システム上で本書の内容を確認し、所定の方法により同意した時点で成立します（基本契約第3条第3項）。
2. 本個別契約の成立後、利用者は、事務局の案内に従い二次創作物を提出し、審査を受けます（基本契約第8条）。
3. 基本契約が終了した場合、本個別契約も同時に終了します（基本契約第12条第3項）。
