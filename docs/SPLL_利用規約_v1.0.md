# SPLL 利用規約（申込窓口の利用条件） v1.0

**文書番号:** SPLL-TRM-001
**版数:** v1.0
**作成日:** 2026-08-13
**位置付け:** SPLL公開申込窓口（ポータル）および提出・検証ページの利用条件
**契約との関係:** 二次創作の利用許諾条件そのものは「SPLL利用許諾契約書」（SPLL-LIC-001）に定めます
**管理:** 管理コンソール「設定 → 同意文・規約 → 利用規約」（`Legal_Documents` の `TERMS`）
**法務ステータス:** ［法務確定前］。CloudSign FORM v4への移行に伴い、本書の位置付けを「窓口の利用条件」へ整理したもの

## 第1条（本規約の適用範囲）

1. 本規約は、TRPGライツ事務局（以下「事務局」といいます。）が提供するSPLL公開申込窓口、作品提出ページ、ライセンス検証ページその他の関連ページ（以下あわせて「本サービス」といいます。）の利用条件を定めます。
2. 二次創作の許諾範囲、利用許諾料、クレジット表示その他の契約条件は、CloudSign上で締結する「SPLL利用許諾契約書」および「SPLL二次創作ガイドライン」に定めます。本規約とこれらが抵触する場合は、利用許諾契約書、ガイドライン、本規約の順に優先します。

## 第2条（申込と契約の成立時点）

1. 本サービス上での申込は、SPLL番号の発行と契約手続の開始を意味するにとどまり、これにより利用許諾契約が成立するものではありません。
2. 利用許諾契約は、CloudSignから送付される契約書の内容を利用者が確認し、CloudSign上で同意した時点で成立します。
3. 本申込窓口は個人（個人事業主を含む）を対象とします。法人によるご利用は、別途の問い合わせ窓口から個別契約でのご対応となります。

## 第3条（利用者の責任）

1. 利用者は、本サービスへ入力・提出する情報が真実かつ正確であることを表明します。
2. 提出作品に第三者の著作物、写真、楽曲、素材その他の権利対象が含まれる場合、利用者は自らの責任で必要な権利処理を行うものとします。
3. 利用者は、発行されたSPLL番号、提出リンクその他のアクセス用リンクを第三者に共有しないものとします。

## 第4条（作品審査・是正）

1. 提出作品はAI（Vertex AI Gemini）による一次審査に付されます。AIの判定は最終決定ではなく、事務局の人的判断と区別されます。
2. 適合性に疑義がある場合、事務局は、表示・内容の修正、公開・頒布の停止その他の是正を求めることができます。

## 第5条（非承認・非保証）

1. 審査の通過、SPLL番号の発行、認証バッジの発行または一定期間の無指摘は、事務局または権利者による公式の承認、適法性の保証、権利非侵害の保証を意味しません。
2. 利用者は、「公式」「公認」その他事務局または権利者による正式な承認があると誤認させる表示をしてはなりません。

## 第6条（禁止事項）

1. 利用者は、本サービスの利用にあたり、次の行為を行ってはなりません。
   1. 本サービスの運営を妨害する行為、不正アクセス、自動化された大量アクセスその他これらに類する行為
   2. 他人になりすまして申込を行う行為、虚偽の情報を登録する行為
   3. SPLL利用許諾契約書第8条およびSPLL二次創作ガイドラインにおいて禁止される行為
   4. 法令または公序良俗に反する行為

## 第7条（サービスの変更・中断）

1. 事務局は、システム保守、障害、外部サービス（CloudSign・formrun・Google等）の事由その他やむを得ない事由により、本サービスの全部または一部を予告なく変更または一時中断することがあります。
2. 前項による中断について、事務局は、故意または重過失による場合を除き責任を負いません。

## 第8条（個人情報）

1. 本サービスにおける個人情報の取扱いは、「個人情報の取得に関する同意事項」（SPLL-PRV-001）に定めるとおりとします。

## 第9条（本規約の変更）

1. 事務局は、本規約を変更することがあります。変更後の規約は、本サービス上に公開した時点から適用されます。
2. 既に成立している利用許諾契約の条件は、当該契約に定める変更手続によります。

## 第10条（準拠法・管轄）

1. 本規約は日本法に準拠し、事務局所在地を管轄する裁判所を第一審の専属的合意管轄裁判所とします。
