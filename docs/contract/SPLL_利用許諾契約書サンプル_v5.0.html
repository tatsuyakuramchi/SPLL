本文

第1条（目的及び契約の構成）

  1. 本契約は、SPLL制度に参加する利用者が、別紙に定める対象原作を利用して二次創作活動を行うための条件を定めるものです。
  2. 本契約は、本契約書及び第3条に基づき本契約に追加される別紙により構成されます。別紙は、本契約に追加された時点で本契約の一部となります。本契約及び別紙の送付時に適用される「SPLL二次創作ガイドライン」（以下「ガイドライン」といいます。）を併せて「本契約等」といいます。
  3. 別紙と本契約書が抵触する場合は、当該別紙に係る許諾に関する限り別紙を優先し、本契約とガイドラインが抵触する場合は本契約を優先します。
  4. 本契約における「事務局」とは、SPLLパートナーシップ契約に基づきSPLL制度の契約管理、SPLL番号の管理、利用状況の確認その他SPLL制度の運営事務を行うSPLL事業TRPG事務局をいい、その代表法人である株式会社アークライトが、各ライセンサーを代表して本契約に関する行為を行います。

第2条（定義）

  1. 「対象原作」とは、SPLL制度に参加する作品のうち、別紙に記載されたものをいいます。
  2. 「別紙」とは、第3条第2項に基づき事務局が作成し電子契約システムで送信する許諾作品通知書をいいます。
  3. 「SPLL番号」とは、事務局が二次創作物ごとに付与する識別番号をいいます。別紙は二次創作物1つにつき1通とし、SPLL番号で特定します。
  4. 「契約番号」とは、事務局が本契約に付与する識別番号をいいます。
  5. 「電子契約システム」とは、ライセンサー又は事務局が指定する電子契約サービス（クラウドサインを含みます。）をいいます。
  6. 「専用ページ」とは、事務局が利用者の登録した電子メールアドレス宛てに通知するリンクからのみ利用できる、利用者専用のウェブページをいいます。
  7. 「料金表」とは、事務局がSPLLウェブサイトで公表する利用許諾料の料金表をいいます。
  8. 「パートナー」とは、SPLLパートナーシップ契約の当事者として、事務局がSPLLウェブサイトで公表するパートナー一覧に掲載された者をいいます。事務局は、パートナー一覧の版及び掲載期間を記録します。
  9. 「二次創作物」とは、利用者が対象原作を利用して制作する作品をいいます。

第3条（別紙の追加）

  1. 事務局は、本契約の成立後、利用者が本契約で登録した電子メールアドレスへ専用ページのリンクを送付します。利用者は、本契約の有効期間中、専用ページから、二次創作物ごとに、その名称（予定）、対象原作、利用区分その他事務局所定の事項を指定して許諾を申し込むことができます。
  2. 事務局は、前項の申込みの内容に基づき、契約番号、SPLL番号、二次創作物の名称（予定）、対象原作、利用区分、許諾期間、利用地域、利用許諾料、支払方法、支払期限、利用報告、権利表記、特約その他の条件を記載した別紙を作成し、電子契約システムを通じて利用者の登録した電子メールアドレスへ送信します。
  3. 別紙は、利用者が電子契約システム上で別紙の内容を確認し、同システム所定の方法により同意した時点で本契約に追加されます。申込みのみでは別紙は追加されません。
  4. 別紙の送信から3か月以内に利用者が同意しない場合、当該別紙は効力を失い、申込みは取り消されたものとみなします。
  5. 事務局は、申込みの内容が本契約等に適合しないと合理的に判断する場合、別紙を送信せず、又は申込みの内容の変更を求めることができます。
  6. 本契約に追加できる別紙の数及び一つの別紙に記載する対象原作の数に上限はありません。
  7. 専用ページへのリンクは利用者本人に限り使用できるものとし、利用者はこれを第三者に開示してはなりません。専用ページからなされた申込みは、利用者本人による申込みとみなします。
  8. 利用者は、専用ページのリンクを紛失した場合、SPLLウェブサイトで契約番号及び登録した電子メールアドレスを入力して、リンクの再送を求めることができます。事務局は、入力された内容が登録と一致する場合に限り、登録した電子メールアドレスへ新しいリンクを送付し、それ以前のリンクは使用できなくなります。

第4条（利用許諾）

  1. 別紙に記載の対象原作の権利者であるライセンサーは、利用者に対し、本契約等の条件に従い、当該対象原作を利用して二次創作活動を行うための非独占的かつ譲渡不能な権利を許諾します。
  2. 前項の許諾範囲は、別紙及びガイドラインに定める利用区分、利用地域その他の条件に限られます。
  3. 本契約等は、対象原作に係る著作権、商標権その他の権利そのものを利用者に移転するものではありません。
  4. 利用者は、別紙の範囲を超える利用を希望する場合、新たな別紙を申し込むものとします。
  5. 事務局は、各ライセンサーから、本契約の締結、別紙の作成及び送信、利用許諾料の受領その他本契約に関する行為を代表して行う権限を授与されていることを表明し保証します。
  6. 各ライセンサーは、本契約の当事者として、本契約等に基づく権利（是正の要求、解除その他の措置を含みます。）を自ら行使することができます。ライセンサーから利用者への通知その他の連絡は、原則として事務局を通じて行います。
  7. 新たにパートナーとなった者は、パートナー一覧に掲載された時点で本契約のライセンサーに加わります。
  8. パートナーでなくなった者が権利者である対象原作について既に効力を生じている許諾は、別紙に定める許諾期間の満了まで存続します。

第6条（利用許諾料、支払方法及び利用報告）

  1. 利用許諾料は、申込みの時点で公表されている料金表に従い算定し、別紙に記載します。
  2. 支払方法は、利用区分ごとに料金表で定める前払い又は後払いのいずれかとし、別紙に記載します。
  3. 利用許諾料は、事務局の代表法人である株式会社アークライトが利用者に請求し、収受します。前払いの別紙については、別紙と同じ書類に請求書を付して交付します。後払いの別紙については、別紙に定める方法で精算又は請求します。
  4. 利用者は、利用許諾料を、別紙に記載の支払期限までに、次の振込先へ支払います。振込手数料は利用者の負担とします。

  5. 振込先は、本契約書及び電子契約システムを通じて交付する請求書にのみ記載し、事務局が電子メールその他の方法で口座情報を通知し、又は変更を案内することはありません。振込先を変更する場合は、第19条に従い本契約を変更します。

  9. 利用報告に基づき利用許諾料が確定する別紙について、利用者は、売上、頒布数その他料金算定に必要な情報を正確に報告するものとします。
  10. 利用者が第4項の振込先へ利用許諾料を支払ったときは、本契約に基づく利用許諾料の支払が完了したものとします。株式会社アークライトとライセンサーとの間の精算は、SPLLパートナーシップ契約に従って行い、利用者の支払義務に影響しません。

第12条（有効期間）

  1. 本契約の有効期間は、本契約の成立日から1年間とします。ただし、期間満了の1か月前までにいずれの当事者からも更新しない旨の通知がない場合、本契約は同一条件で1年間更新され、以後も同様とします。
  2. 各別紙に基づく許諾の期間は、別紙に定めるとおりとします。ただし、本契約の有効期間を超えることはありません。
  3. 本契約が終了した場合、すべての別紙に基づく許諾も同時に終了します。別紙が取り消され、又は別紙に基づく許諾の期間が満了しても、本契約及び他の別紙は終了しません。

第13条（解除）

  1. 当事者の一方が本契約に違反した場合、相手方は、相当の期間を定めて是正を求め、当該期間内に是正されないときは、本契約の全部又は一部（特定の別紙に係る部分を含みます。以下本条において同じ。）を解除することができます。
  2. 前項にかかわらず、次の各号のいずれかに該当するときは、相手方は催告なく直ちに本契約の全部又は一部を解除することができます。
    1. 第5条の表明保証に重大な違反があったとき
    2. 第9条の禁止事項に重大な違反があったとき
    3. 権利侵害その他違反の性質上、是正が困難であるとき
    4. 支払停止、支払不能、破産手続開始その他信用状態に重大な変化が生じたとき
    5. その他本契約を継続し難い重大な事由があるとき
  3. ライセンサー又は事務局は、緊急の権利保護が必要な場合、解除に先立ち又は解除と併せて、利用の一時停止その他必要な措置を求めることができます。

第14条（終了後の取扱い）

  1. 本契約が終了し、又は別紙に基づく許諾が終了した場合、利用者は、その後新たに終了した許諾に基づく二次創作物を製造、複製、公開、頒布又は配信してはなりません。
  2. 終了時点で既に製造済みの在庫、公開済みコンテンツその他の取扱いは、終了原因、違反の有無その他の事情に応じ、事務局又はライセンサーの合理的な指示に従うものとします。
  3. 重大な契約違反を理由として解除された場合、ライセンサーは、権利保護のため必要な範囲で、公開停止、削除、在庫頒布停止その他の措置を求めることができます。
  4. 既に支払われた利用許諾料は、法令上返還が必要な場合又はライセンサーの責めに帰すべき事由がある場合を除き、契約終了のみを理由として返還されません。

第15条（電子的方法による契約締結及び通知）

  1. 利用者は、SPLL申込サイトから遷移する申込フォームに必要事項を入力します。申込フォームへの入力又は送信のみでは、本契約は成立しません。
  2. 申込フォームに入力された情報に基づき作成された本契約書が、電子契約システムを通じて利用者へ送信され、利用者が同システム上で本契約書の内容を確認し、同システム所定の方法により同意した時点で本契約は成立します。
  3. 本契約及び別紙への同意を証する電磁的記録は電子契約システム上に記録され、専用ページからの申込みの記録は事務局が記録します。事務局又はライセンサーは、契約管理上必要な範囲でこれらを保管します。
  4. 本契約等に関する通知その他の連絡は、利用者が本契約で登録した電子メールアドレスその他事務局が指定する電子的方法により行うことができます。
  5. 利用者は、登録した電子メールアドレスその他の連絡先に変更が生じた場合、事務局が指定する方法により変更を届け出るものとします。

第16条（個人情報）

  1. 事務局及びライセンサーは、利用者から取得した個人情報を、SPLL利用許諾契約の締結・管理・履行、SPLL番号及び認証の管理、利用料の請求・収受、利用状況の確認、違反対応、連絡、問い合わせ対応その他SPLL制度の運営に必要な範囲で取り扱います。
  2. 詳細は、申込時に表示されるプライバシーに関する通知及び事務局又はライセンサーが別途定めるプライバシーポリシーによります。
  3. 事務局及びライセンサーは、前項の目的に必要な範囲で、申込フォーム、電子契約、決済その他の業務を提供する委託先に個人情報の取扱いを委託することがあります。

第17条（反社会的勢力の排除）

  1. ライセンサー及び利用者は、自らが暴力団、暴力団員その他これらに準ずる反社会的勢力に該当せず、これらと社会的に非難されるべき関係を有しないことを表明し保証します。
  2. ライセンサー及び利用者は、自ら又は第三者を利用して、暴力的要求、法的責任を超える不当要求、脅迫的言動、信用毀損、業務妨害その他これらに準ずる行為を行わないものとします。
  3. 相手方が前二項に違反した場合、他方当事者は、何らの催告を要せず直ちに本契約を解除することができます。

第18条（責任）

  1. 利用者は、自ら制作、公開又は頒布する二次創作物について責任を負います。
  2. 当事者の一方が本契約等に違反し、相手方に損害を与えた場合、当該当事者は、法令に従いその損害を賠償する責任を負います。
  3. ライセンサーは、本契約等に明示的に定める場合を除き、利用者の二次創作物の内容、商品性、特定目的適合性又は第三者権利非侵害を保証するものではありません。

第19条（本契約及びガイドラインの変更）

  1. 本契約に追加された別紙の内容の変更は、当事者間で別途合意した場合に限り行います。
  2. ライセンサー又は事務局は、法令の変更、SPLL制度の運営上の必要その他合理的な理由がある場合、民法その他の法令に従い、本契約又はガイドラインを変更することがあります。
  3. 前項の場合、変更内容及び効力発生日を、SPLLウェブサイトその他適切な方法により周知します。
  4. 対象原作、利用区分、利用許諾料その他別紙で定めた事項を利用者に不利益に変更する場合は、法令又は本契約に別段の定めがある場合を除き、利用者の同意を得ます。

第20条（準拠法及び管轄）

  1. 本契約等は日本法に準拠します。
  2. 本契約等に関して紛争が生じた場合、ライセンサー及び利用者は、まず誠実に協議して解決を図るものとします。
  3. 協議によって解決しない場合、事務局の代表法人である株式会社アークライトの本店所在地を管轄する地方裁判所又は簡易裁判所を、第一審の専属的合意管轄裁判所とします。

第21条（存続）

第10条、第14条、第16条、第18条、第20条その他その性質上契約終了後も存続すべき条項は、本契約の終了後及び別紙に基づく許諾の終了後も有効に存続します。

本契約の成立を証するため、本契約書の電磁的記録を作成し、利用者及び事務局が電子契約システム上で合意の措置を講じ、各自その電磁的記録を保管します。
