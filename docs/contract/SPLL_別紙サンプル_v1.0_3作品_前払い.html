確認事項

  1. 本別紙は、利用者が電子契約システム上で同意した時点で本契約に追加されます（本契約書第3条第3項）。送信から3か月以内に同意がない場合、本別紙は効力を失います（同第4項）。
  2. 前払いの場合、許諾は事務局が入金を確認した時点で効力を生じます。本別紙の追加から3か月以内に入金が確認できない場合、本別紙は効力を失います（本契約書第6条第5項）。
  3. 後払いの場合、許諾は本別紙の追加の時点で効力を生じます。支払期限までにお支払いがない場合、認証が一時停止されることがあります（本契約書第6条第6項）。
  4. 利用許諾料は、本契約書第6条に記載の振込先へお支払いください。事務局が本別紙や電子メールで口座情報をお知らせすることはありません。
  5. 二次創作物は、許諾の効力が生じた後、事務局の案内に従い提出し、審査を受けてください。認証及び認証バッジは、審査で承認された後に発行されます（本契約書第8条第5項）。
  6. 本契約が終了した場合、本別紙に基づく許諾も同時に終了します（本契約書第12条第3項）。
