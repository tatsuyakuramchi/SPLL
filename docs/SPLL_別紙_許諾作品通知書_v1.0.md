## 確認事項

1. 本別紙は、事務局が利用者の登録メールアドレスへ送付した時点で本契約に追加され、許諾の効力が生じています（本契約書第3条第3項）。
2. 本別紙の内容が申込みの内容と異なる場合は、送付から7日以内に事務局へお申し出ください（本契約書第3条第4項）。
3. 利用許諾料は、支払期限までに本契約書第6条に記載の振込先へお支払いください。事務局が本別紙や電子メールで口座情報をお知らせすることはありません。支払期限までにお支払いがない場合、認証が一時停止されることがあります（本契約書第6条第4項）。
4. 二次創作物は、事務局の案内に従い提出し、審査を受けてください（本契約書第8条）。
5. 本契約が終了した場合、本別紙に基づく許諾も同時に終了します（本契約書第12条第3項）。
