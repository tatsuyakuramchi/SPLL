SPLL 業務レーン図

利用許諾契約の締結から認証バッジまでを、誰が・どの画面で・どのシステムを使い、どの時点でどの文書が出るかで並べた図です。左から右へ時間が進みます。

クリエーター・事務局が操作する画面 システムの処理（すぐ返す） 定期実行・日次バッチ 発行される文書 設計中の文書 メール

画面の一覧

画面置き場所使う人本人の確かめ方・データの出どころ
入口サイト（説明・同意）AWS（CloudFront＋S3、受付番号は Lambda）クリエーターGAS を呼ばない。受付番号（署名つき）を formrun の隠し項目へ渡す
契約者情報の入力formrunクリエーター氏名・住所・メールは formrun が受け取る。SPLL は締結後に CloudSign から氏名・メールだけを取る（住所は持たない）
契約書・別紙の確認と同意CloudSignクリエーター利用許諾契約書はテンプレート、別紙と請求書は SPLL が作った PDF
専用ページAWS が配信、データは GASクリエーター専用ページのトークン（登録メールにだけ送る長期リンク）。作品の選択・申込、別紙と状態の一覧、提出・バッジへの入口
提出ページAWS が配信、データは GASクリエーター提出用トークン（専用ページから都度発行）。許諾が有効な案件だけ
検証ページAWS が配信、データは GASだれでもバッジの QR。認証 ID と照合コード
案件ボード（管理画面）GAS（社内ドメインのみ）事務局・法務・審査状態の一覧とステータススイッチ、入金CSVの取込
設定・事務局運営パネルGAS（社内ドメインのみ）事務局料金表（支払方法）、法務文書、会議・議決・精算

文書の発行タイミング

文書いつ作る届け方保管
① 利用許諾契約書formrun の送信直後（クリエーター1人につき1回）CloudSign のテンプレート（formrun が当事者欄を差し込む）CloudSign締結済み PDF を Drive に保存（GAS の定期実行）
② 別紙（許諾作品通知書）専用ページの申込の後、1分ごとの定期実行でGAS（申込時に確定した条件から）CloudSign API。同意で本契約に追加送信版と締結済み PDF、照合コード
③ 請求書発行者は検討中②と同時（前払いの別紙だけ。同じ PDF の後ろのページ）GAS（請求書番号を採番）②と同じ②と同じ PDF、請求書番号を台帳へ
④ 認証バッジ・検証ページ審査の承認後（支払方法にかかわらず）GAS（バッジ生成ジョブ）専用ページから取得、メールでお知らせDrive
⑤ 精算書（電子書籍・後払い）設計中配信会社からの入金の後（周期は未定）未定未定未定
メール契約番号の発行後：専用ページのリンク／審査の承認後：審査完了・バッジGASメール（口座情報は書かない）通知の記録

③の発行者は「アークライトが各パートナーの代理として一括で発行（媒介者交付特例）」と「パートナーごとに発行」のどちらにするか検討中。

システムの使い分け

システム役割この図での出番
AWS入口だけ。画面の配信、GAS への中継（共有鍵・回数制限）、受付番号、Webhook の中継入口サイト、専用ページ・提出・検証ページの配信、締結 Webhook の中継
formrun契約者情報の入力利用許諾契約の入力画面
CloudSign契約書・別紙の送付と同意、締結の通知①の締結、②③の同意
GAS（すぐ返す処理）Webhook の受信記録、専用ページの表示内容、申込の受付受信・受付の記録だけ（重い処理をしない）
GAS（定期実行・1分）契約番号の発行、SPLL番号・条件の確定、別紙・請求書の PDF、CloudSign への送信、AI 一次審査、バッジ生成図の緑の箱
GAS（日次バッチ）3か月の期限切れの取消、後払いの期限超過、締結の照合（取りこぼし対策）図の右端
スプレッドシート・Drive台帳（契約・案件・受付・入金）と文書の保管すべての処理の記録先
経理入金CSVを出す。電子書籍の精算は設計中前払いの入金、電子書籍の入金
